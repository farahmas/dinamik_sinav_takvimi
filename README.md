### 🎯 Overview

**Dinamik Sınav Takvimi** is a desktop application built with **Python** and **PySide6 (Qt for Python)**.  
It automates the creation of **exam schedules** and **seating plans** for university departments, ensuring no student or room conflicts occur.

The app provides separate dashboards for **Admins** and **Coordinators**, allowing easy management of:
- Courses  
- Students  
- Classrooms  
- Exam dates & times  
- Seating arrangements (with PDF export)

---

## 🚀 Features

✅ Automatic exam scheduling without time conflicts  
✅ Smart room assignment based on capacity  
✅ Excel import/export for students and courses  
✅ Visual seating plan generation (PDF support)  
✅ Role-based login (Admin / Coordinator)  
✅ Modern responsive PySide6 interface
